## Upload to GitHub
1. Create a new repository on https://github.com/new.
2. Choose a repository name.
3. Upload `README.md` and `project-demo.mp4` using **Add file → Upload files**.
4. Select **Commit changes**.

> Note: This package contains only the video supplied. Add your source-code and project files separately if you want the repository to contain the actual project.
